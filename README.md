# TravelZen
TravelZen is a premium, fully responsive  web application designed to deliver a luxury travel booking experience.

**TravelZen** is a premium, fully responsive front-end web application designed to deliver a luxury travel booking experience. Built entirely with vanilla HTML, CSS, and JavaScript, it features a modern glassmorphism UI, simulated authentication, and interactive booking modals.

## ✨ Key Features

*   **Premium UI/UX Design:** High-end typography pairing (*Playfair Display* & *Outfit*), soft drop shadows, CSS gradient overlays, and smooth hover animations.
*   **Fully Responsive Layout:** Flawless rendering across mobile, tablet, and desktop devices utilizing advanced CSS Grid and Flexbox architectures.
*   **Simulated Authentication Flow:** Uses browser `localStorage` to manage user state, allowing users to toggle between Login/Signup forms and dynamically updating the navigation interface upon authentication.
*   **Interactive Booking System:** Features an animated modal popup that auto-populates package data and culminates in a beautiful, personalized success confirmation screen.
*   **Form Validation:** Built-in client-side validation for contact inquiries and booking procedures.
*   **Clean Architecture:** Follows DRY (Don't Repeat Yourself) principles with a centralized `style.css` and `script.js` powering the entire multi-page application without relying on heavy external frameworks.

## 🗺️ Project Structure

The application consists of 6 core interconnected pages:

*   `index.html` - The landing page featuring a massive hero section, trending destinations, and best-selling packages.
*   `about.html` - Corporate overview highlighting agency statistics, mission statement, and core values.
*   `destinations.html` - An image-centric grid of global locations with interactive overlay detail cards.
*   `packages.html` - Detailed itinerary cards featuring pricing, included amenities, and dynamic "Book Now" triggers.
*   `contact.html` - A modern split-screen layout featuring agency contact information and a functional message form.
*   `login.html` - A seamless authentication portal with toggles for Sign In and Account Creation.
